> teens real life safety skills for when they're home alone.

## 💡 Inspiration

When brainstorming ideas for Track 1, we kept coming back to one 
question — what's more of a childhood classic than Home Alone? 
Almost every kid has watched it and imagined what it would be like 
to actually be home alone. We wanted to gamify that fantasy in a 
way that was not only fun and nostalgic but also genuinely useful. 
A lot of kids today are home alone more than ever, and we noticed 
there's a real gap in safety awareness — kids are so wrapped up in 
their own world that basic situational awareness just isn't there. 
So we built a game that sneaks in real safety lessons while you're 
having fun defending Kevin's house.

---

## 🕹️ What It Does

Three Nights at Kevin's is a survival game where you play as Kevin, 
defending his house across three increasingly difficult nights. Each 
night introduces new challenges and tougher decisions — you have to 
react quickly and make the right calls to survive. The game is 
designed so each night teaches a different real-world safety concept, 
from locking doors and windows to knowing when to call for help. 
Survive all three nights and Kevin makes it to Christmas morning.

---

## 🔧 How We Built It

We built the entire game in Unity 6 using C# for all our game logic 
and interactions. Our character sprites were hand designed by us 
using Pixilart, which was a fun and surprisingly challenging process. 
Background scenes were generated using Grok AI and then integrated 
into Unity as pixel art assets. We used open source sprite animation 
tools to handle character movement and interactions. Claude AI was 
used as a learning tool throughout — we had zero Unity experience 
coming in and used it to understand C#, debug issues, and learn how 
Unity's component system works.

**Built with:**
- Unity 6 (Game Engine)
- C# (Scripting)
- TextMeshPro (UI Text rendering)
- Unity Universal Render Pipeline (URP)
- Pixilart (Sprite design)
- Grok AI (Background image generation)
- Claude AI

## 🌟 What Makes It Unique
Three Nights at Kevin's is unique because it takes a universally loved childhood movie and turns it into something genuinely useful — a safety education tool disguised as a fun game. No one has tackled home-alone safety for kids this way before, and the fact that we built it in 24 hours with zero prior Unity experience makes it even more special.
